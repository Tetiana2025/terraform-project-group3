# Terraform AWS WordPress Deployment

## Overview

This Terraform configuration sets up a WordPress application on AWS with the following components:

- VPC with 3 public subnets
- Internet Gateway and Route Tables
- EC2 instance running Amazon Linux 2
- RDS MySQL database
- Security Group allowing HTTP and SSH access

terraform init
terraform apply -var
